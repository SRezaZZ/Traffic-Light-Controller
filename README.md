# Traffic Light Controller

A synthesizable Verilog RTL implementation of a two-way traffic light controller using a finite state machine (FSM) and a dedicated timer module.

The project includes functional simulation, verification, and FPGA synthesis using Xilinx Vivado.

## Project Goals

The primary goal of this project was to strengthen my practical **Git and GitHub workflow** through the development and documentation of a real Verilog project.

At the same time, the project was used to reinforce fundamental concepts of **Verilog HDL, finite state machines (FSMs), timers, modular design, functional verification, and FPGA synthesis**.

## Features

- 5-state FSM-based traffic control
- Parameterized timing
- Reset and standby support
- Dedicated verification testbench
- Functional simulation
- FPGA synthesis

For the complete technical design, see [DESIGN.md](docs/DESIGN.md).
